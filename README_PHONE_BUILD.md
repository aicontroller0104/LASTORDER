# LAST ORDER — Android Cloud Build v1

Windows/Android Studio 없이 Android 휴대폰에서 관리하고 Expo/EAS Cloud Build로 APK를 만들기 위한 프로젝트입니다.

- App.js: Android WebView 진입점
- assets/index.html: 게임 프로토타입
- app.json: 앱 설정
- eas.json: APK/AAB 빌드 설정
- package.json: Expo 프로젝트 설정

preview 프로필은 직접 설치 가능한 APK용입니다.
production 프로필은 Android App Bundle(AAB)용입니다.
